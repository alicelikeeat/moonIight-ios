# Golden World 技术实施书（v1）

目标：先做出一座达到参照标准的城镇「月光水晶城」，再把它的建筑、布局和材质规则提炼成可复用的工具，让世界导演按同样规则生成其他城镇。整片 4096×4096 大陆不在本阶段范围内。

本文说明的是代码里已经实现的内容。没做或没验证的部分，统一列在最后一节。

## 0. 对原计划的调整

| 原计划 | 实际做法 | 原因 |
|---|---|---|
| 用 USDZ 模型或程序化几何做建筑套件 | **只用程序化模块**，展开成普通 `SpatialBlock` | 碰撞、存档、撤销、编辑、两种视角都直接沿用现有数据，不需要第二套建筑格式；没有外部素材，也就没有授权问题；方块数量可以精确计入预算 |
| 存档里保存完整城镇蓝图 | 只保存 **种子 + 城镇意图**（`GoldenTownIntent`），城镇规划每次按种子重新算出 | 存档不会塞进几千条格子列表；同一种子一定得到同一座城 |
| 屋顶、墙按方块逐个隐藏 | 改为 **按建筑的屋顶 / 每一面墙** 打标签，渲染时合并成少量网格 | 原来每个屋顶块、墙块都是单独对象，一座城上千个，帧率扛不住；现在一侧墙只有一两个网格 |
| 像素模式只在室内收屋顶 | 再加 **透视（x-ray）**：挡在镜头和玩家之间的建筑，像素模式收屋顶并淡化墙，3D 模式淡化屋顶和墙 | 玩家走到房子后面时，两种视角都不会看不见人 |
| 新写一个世界导演 | 在原有世界导演上加 `crystalKingdom` 主题：规划、搭建、评分都走原来的流程，只多接一步城镇构建和一道质量门槛 | 不并行维护第二套世界逻辑 |
| 一次做五个美术风格包 | 先做 **水晶幻想**（默认）和 **古典幻想** 两个，用来证明抽象可行；赛博、水墨、油画留给以后 | 风格包只是数据，以后可以逐个添加，不用改布局代码 |
| 一次性交付并宣称完成 | 交付全部代码和自动化检查；**参考画面截图、真机帧率和内存仍待人工验收** | 云端编译和逻辑检查通过，不等于真机验收通过 |

## 1. 建筑套件标准（`Features/HybridWorld/ArchitectureKit.swift`）

### 1.1 网格与尺寸

| 量 | 值 | 说明 |
|---|---|---|
| 格 | 1 格 = 1 m | 与 256×256 地图一致 |
| 层高 | 3 | `KitMetrics.storey` |
| 门 | 宽 2 格、高 2 格；城门宽 4 格，整层打通 | `doorWidth` ∈ {2, 4} |
| 窗 | 窗台 1、窗洞 1、窗楣 1 | 每 `windowEvery` 格一扇（0 表示不开窗） |
| 墙厚 | 1 格，位于占地外圈 | 墙角和门框用 `trim` 材质 |
| 屋檐出挑 | 1 格（平顶没有出挑） | `roofBounds` |
| 坡度 | 坡顶、四坡顶每向内一格升高 0.5；尖顶升高 1.0 | |
| 占地 | 4–24 格见方，1–6 层 | `KitBuildingSpec.valid` |
| 台阶 | 每级 0.4（玩家一步最多上 0.5） | 城堡台阶 |

### 1.2 模块

- 墙：实墙、窗墙、门（门楣）、穿堂门（`passage`，前后都开）、柱（敞开的亭子 `open`）
- 屋顶：坡顶（屋脊每三格一颗水晶脊饰）、四坡顶、尖顶、平顶（带女儿墙），尖顶可以加水晶顶饰 `finial`
- 附件：阳台（门上方，两层以上才有）、旗帜、招牌、室内柜台和灯（`furnished`）
- 城市设施：路灯、水晶簇、长椅、矮篱笆、花坛、摊位、喷泉（石沿、水面、立柱、两层水晶）

### 1.3 连接点

- **门的接口** `doorSocket`：门外正对的那一格。规划器从这里笔直往外铺小路，一直接到最近的道路，最多 14 格。
- **屋顶的落点**：屋顶块从檐口高度 `eaves` 开始。玩家在占地内、而且低于 `eaves` 时算在室内。
- **遮挡边界** `BuildingOccluder`：占地范围、檐口高度、屋顶最高点 `roofTop`、地面高度 `base`、建筑组 `groupID`。

### 1.4 材质槽和风格包

模块只说明自己要哪个槽：`wall, trim, roof, window, accent, street, plaza, water, metal`。风格包（`ArtStyle.pack`）为每个槽指定颜色、语义材质和渲染角色。

| 槽 | 水晶幻想 | 古典幻想 |
|---|---|---|
| wall | 白石 F1EEE8（`whiteStone`，不透明） | 灰泥 E9DCC4 |
| trim | 浅灰石 D6D2CA | 木 7A5A3C（`wood`） |
| roof | 冷蓝玻璃 8FB8E0（`roofGlass`） | 红瓦 B5523B（`roofTile`） |
| window | BFE3FF（`windowGlass`） | CFE6F2 |
| accent | 发光水晶 F7FBFF（`landmarkGlass`） | 金 E8C468 |
| street / plaza | 白石 / 晶体街面 | 石板 |

## 2. 两种视角的材质映射（`GlassMaterialResolver`）

同一个方块只存一份数据：颜色、语义材质、渲染角色。两种视角只是解析方式不同：

| | 像素俯视（`.pixel`） | 第三人称 3D（`.spatial`） |
|---|---|---|
| 着色 | 无光照、硬边 | 基于物理的材质（PBR） |
| 颜色 | 每个通道吸附到 0x20 的整数倍，形成小色板 | 原色 |
| 石、木、瓦、金属 | 不透明 | 不透明；金属的金属度为 0.7 |
| 玻璃屋顶、窗 | 基本不透明 | 半透明，带清漆高光 |
| 地标 | 不开高价高光通道 | 高画质时开启 `prioritySpecular` |
| 屋顶 | 在室内或被透视时直接剪掉 | 被透视时淡化 |

切换视角时只改变 `HybridWorldSave.viewMode`、相机和材质预设。位置、碰撞、方块和时钟都不变，由 `PerspectiveContinuity` 检查保证。

## 3. 城镇布局（`Features/HybridWorld/GoldenCity.swift`）

核心城区是 80…175 的 96×96 范围，整体放在 256×256 区域内（大陆坐标第 7 列第 7 行）。

| 方位 | 内容 |
|---|---|
| 北 | 高 2 的城堡台地（x 100–155，y 152–168），5 级台阶；月光尖塔（地标，位于主路轴线上）、东西两座翼殿、东西两座塔 |
| 中 | 24×24 环纹广场，水晶喷泉，四角有灯、水晶和长椅 |
| 东 | 水晶铺、三座民居和礼拜堂；房后是东园（花坛、篱笆、树） |
| 西 | 旅馆（可以进去，带柜台）、工坊、杂货铺、敞开的市集（摊位）、图书馆 |
| 南 | 南门（穿堂门楼）、卫兵所、旅人驿站；城外有河（或湖）和石桥 |
| 外围 | 城墙和四座墙塔；东、西、南三条城外道路（离城门 10 格以外开始蜿蜒）；森林；北方远山（由世界导演的地形阶段生成） |

规则：

1. 占地是事先设计好的，相邻建筑之间留 2 格，**屋檐也不会碰到一起**（有自动检查）。
2. 每个种子会改变层数、屋顶形式、开窗节奏、阳台和招牌；之后再检查，保证任意两座非墙塔建筑的外观签名都不相同。
3. 意图来自描述文字：提到「湖」就把河换成湖和长堤；提到「古典 / 木屋 / 砖」就换成古典风格包；提到「笔直 / 棋盘」道路就不弯；还可以关掉森林或远山。
4. 摆放顺序和预算：
   - 0 级：台地、城堡、城门、城墙、主街、广场、喷泉
   - 1 级：街区建筑、门前小路
   - 2 级：河、桥、墙塔
   - 3 级：城外道路、街道设施

   建筑是一个整体，要么整座放下，要么整座不放。

| 预算 | 方块 | 植物 |
|---|---|---|
| 低 | 8 500 | 700 |
| 标准 | 12 000 | 1 100 |
| 高 | 15 000 | 1 600 |

世界导演在此基础上为远山另加 1 200 块。

5. 不覆盖玩家内容：只要建筑的任何一格有玩家自己做的方块，这座建筑就整座跳过；道路和装饰按格跳过。

## 4. 世界导演升级

- 新主题 `crystalKingdom`（月光水晶城）。规划器调用城镇规划，把街区写进蓝图的区域列表，地标写成城堡，路线是「石桥 → 城门 → 广场 → 台阶 → 城堡」，同时加北方远山。
- 蓝图只新增一个可选字段 `town: GoldenTownIntent?`，旧蓝图照常读取。
- 搭建：先放城镇（按图层过滤），再放生物和远山。方块 id 末尾带 `:gc`，同时保留图层标签，所以局部重新生成仍然有效。只要建筑有一部分要被替换，就整座替换，不会留下半座房子。
- 评分：原来的评估（数据、可达性、预算、构图……）之后，再加 Golden Scene 质量门槛。门槛里的任何一项不通过，都会以 `golden:` 前缀记为硬性违规。

## 5. Golden Scene 质量门槛（`GoldenSceneQualityGate.swift`）

| 检查 | 不通过的条件 |
|---|---|
| 视觉中心 | 地标比其他结构高出不到 4 格，或者偏离主路轴线 |
| 重复 | 有两座建筑签名相同，或者关键建筑少于 12 座 |
| 穿插 / 悬空 | 实心块互相重叠；实心块下方没有支撑，旁边也没有可以依附的块 |
| 连通 | 从出生点（每步最多升高 0.5）走不到某扇门或某个室外观察点 |
| 像素视角遮挡 | 经过收屋顶和透视之后，抽样街道中仍有超过 10% 看不到玩家，或者有观察点看不到玩家 |
| 3D 完整度 | 屋顶块数少于占地面积，或者四面墙不全 |
| 3D 构图 | 从城门观察点的 3D 镜头看不到尖塔顶端（不算透视） |
| 材质 | 有方块的颜色不在风格包色板内 |
| 预算 | 方块或植物超出预算 |
