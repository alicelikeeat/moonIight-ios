## 代码与实施范围

- `MoonTreasureMapView.swift`：自由散落 / 视频墙独立切换，常驻 SKView，返回自由模式不主动重新配置场景；数据变更再同步。动态预览在墙模式关闭。原生玻璃底层只读跟随物理卡片，单独投影刷新，不参与命中。动态字体放大卡片，VoiceOver 使用整理布局。
- `TreasureVideoSelectionModel.swift`：有序唯一选择、最大 10、默认目标 4（空选择，不伪造媒体）、恢复截断提示、删除剔除、顺序与洗牌、列数和性能策略。
- `TreasurePlaybackCoordinator.swift`：AVPlayer 生命周期与三种模式、单一音轨 / 全静音、循环、异步任务及 KVO/通知清理、播放错误、热状态 / 低电量 / 内存预算、后台与网络暂停。
- `TreasureVideoWallView.swift`：可搜索选择器、清空、序号、上限禁用、可滚动 10 项网格、聚焦、统一控制；使用非交互原生 marker 测量滚动视口交集，不将预加载误认为可见。
- `TreasureAppearance.swift`：独立背景存储，仅迁移旧 JSON 的背景字段；移除的目标、自动播放、图片时长和声音组合不执行。
- `RootView.swift`：个人页“库”下方独立全屏入口。库的业务、收藏和普通 MediaPlayerView 保留；搜索“视频墙”进入新路径。
- `MoonlightApp.swift`：旧 `treasurePlayback` raw value 保留已保存菜单的兼容，显示和搜索路由改为视频墙。
- PBX 注册、真实 H264 测试资源、纯策略与 UI 用例、中文发布说明、334 个控件入口清单同步更新。

### 已定位及处理的失败

1. 首轮视频墙已选 10 个但播放器为 0，可见集合未更新；改为直接观察 UIScrollView 的交集，不再依赖丢失的 SwiftUI preference。
2. 播放探针只在 body 更新时读取 rate，造成已建立播放器但 advancing 一直为 0；DEBUG 探针改为 200ms 读取实际播放进度，未放宽“必须前进”的断言。
3. 原标签 + Switch 合并的可访问框中心落在空隙，循环/静音点击没有改变值；改为有明确 51×44pt 区域的原生开关并检查其状态。
4. 场景读出点被其他卡片遮挡时，拖拽测试没有命中卡片；探针改为选择真正处在前面的卡片，仍检查移动、持有帧数、漂移、取消及物理恢复。
5. HStack 父 identifier 覆盖了自由散落 / 视频墙按钮 ID；移除父 ID，分别保留独立按钮标识。
6. 已结束或失败的同时播放器释放占用，接续加载其他可见项；选择仍保留，失败明确提示。增加单项不循环自然到尾部的真实播放用例。

## 运行与真机差异

本地执行环境为 Linux，没有 Xcode，按要求只由 GitHub macOS 编译和运行 iOS 模拟器；未在本地编译 iOS，未做真机验收。模拟器视频为实际本地 H264 资产，能够验证 AVPlayer 状态与时间前进；音轨唯一检查使用 isMuted 状态，不代表已经听测真实有声音轨。

## iPhone 必验清单

- 选择 1、4、9、10 个不同本地 / 网络视频；真实 4K、高码率、长片下滚动至第 10 格，检查等待提示、掉帧、内存、发热及耗电。选择上限 10，当前并发预算为 1–6，不能声称保证 10 路解码；分辨率和带宽偏好不保证远端提供对应流。
- 原声、全部静音、切换音轨、聚焦及返回；静音键、耳机拔插、来电/中断、锁屏和前后台没有重复或残留音频；恢复须显式点击播放。
- 远程断网、403、无效文件、视频被删除、选择恢复超过 10 个的提示与重选；普通库、收藏、原播放器与搜索均保持原功能。
- 进入/离开墙及快速切模式、反复聚焦、长时间循环后的播放器回收和内存。
- 自由卡片重力/碰撞、甩动、0.5 秒长按、>10pt 取消长按、双指与触摸取消、倾斜、摇晃；切回位置保留。原生玻璃跟随物理的视觉与性能需低性能设备核对。
- iOS 16 Material 与 iOS 26 原生玻璃，深浅色、动态字体、VoiceOver 整理路径、减少动态 / 透明度、增强对比度、44pt 命中和底部安全区域。
