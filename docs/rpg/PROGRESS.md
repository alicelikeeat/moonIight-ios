本地为 Linux；编译交由 GitHub。真机 Instruments、60 FPS、内存峰值和最低机型仍未验证。已有斗地主保持原状，独立开发暂缓。

P5 保守总预算为 0–2 路；背景最多 1、玩家最多 1、互动最多 2 是角色上限而非合计承诺。同一素材共享时间轴，多个可见实例中任一启用循环则该共享素材循环；全不循环时完成后释放槽位。尚无真实 iPhone 数据，不开放 3–4 路。

P5 新增 schema 2，读取 schema 1 时补媒体预算/背景层及早期差量默认值，保留旧 Seed、实体、玩家与已有差量；未知版本仍拒绝并保留文件。图片/视频显示与逻辑碰撞独立，RPG 离线只使用本地可读取素材。

P6 schema 3 迁移 schema 1/2：保留世界与玩家，补齐战斗/朝向/装备默认值。战斗高频更新只更新 SpriteKit 敌人节点和独立 HUD，不每帧发布根页面世界状态。实机性能仍待验证。

P7 schema 4 将剧情与世界一起存储，节点执行回执与掉落共同提交，条件等待不重复奖励；图最多 256 节点并拒绝断链及循环，事件计数保留已发生任务事实。

P8 schema 5 追加媒体演出进度，迁移旧剧情保留节点与奖励回执。草稿发布总是新身份，旧剧情及其官方/自制进度不被覆盖；隔离预览不写原世界。演出与旧页面互斥运行，复用受限帧池，默认静音。

P9 保持 schema 5 单个世界 JSON 同时保存建造、战斗、剧情回执与演出位置，主文件和备份取最高有效修订；主文件损坏时也拒绝过期快照。未来 schema/generator 直接报错并保留文件，不静默降级。活动世界索引最后写入，创作副本索引中断不覆盖原世界。新增 before/after backup、primary、pointer 的磁盘故障测试，测试结果待 GitHub。

P10 schema 6 增加方块触发器（点击/接近/攻击/计时/剧情事件），触发已校验的 StoryGraph，复用白名单事务和一次性回执，不执行脚本。旧世界迁移默认无行为，官方保护区不能绑定。统一搜索新增剧情、编辑器和运行诊断的直接入口，原沙盒入口保留。

运行诊断只保留 600 个帧间隔，统计 FPS、p95、>50ms 帧、内存 footprint、解码器与缓存、区块加载、保存及视角首帧耗时；暂停不计入采样。没有真实设备报告，不宣称达到 60 FPS 或内存目标。
