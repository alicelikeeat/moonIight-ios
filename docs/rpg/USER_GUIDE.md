# 自由媒体沙盒预览版使用说明

从「我 → 自由媒体沙盒」进入，原五个 Tab、月藏图、视频墙和斗地主保留。也可在智能搜索中输入「沙盒」「剧情编辑器」「序章」「沙盒运行诊断」。真实 iPhone 性能仍未验证。

## 完成序章与第一章

1. 打开「工具 → 剧情与任务」，读完序章并选择开场分支，收到收集材料任务。
2. 返回世界，先向上移动三格，再到工具里「选取附近空地」。选择木材方块，关闭工具后「放置」，再「挖掘」三次，破坏自建木块即可完成第一次方块事件。也可探索保护区外并采集自然资源。
3. 返回剧情，检查任务条件；序章奖励与任务回执共同保存。使用剧情中的「沿通路前往月光村」开始步行导航，手动方向输入会取消导航。
4. 到村庄后继续对白，选择交出两块石材修理守卫，或选择战斗。两条分支都能完成第一章，选择和奖励保留。
5. 战斗分支需要关闭工具返回场景，用攻击、范围技能和翻滚击败守卫，再回到剧情检查任务。战斗中不能切换视角或更换装备。生命耗尽时可安全复苏，敌人不会因切换视角恢复生命或重复掉落。

## 双视角与建造

- 俯视使用八向移动；侧视的上键用于跳跃，支持空中攻击与冲刺。
- 只能从双界神殿安全入口进入侧视，返回时需落地并回到入口附近。创造模式可在工具里定位神殿，冒险模式可沿通路导航。
- 方块选择、绘制、范围填充、复制/粘贴、挖掘、撤销/重做在工具和场景操作区中。批量操作先校验边界、资源、占用与保护区。
- 创造模式免资源成本，但官方锚点和通路仍受保护。需要修改保护区时，先创建独立创作副本；原世界保持独立。

## 图片、视频和声音

工具中的媒体外观可为角色、背景层和选中方块选择本地素材，或通过相册导入。显示尺寸、锚点、裁切与碰撞范围分离；可选择循环、静止预算和声音。

RPG 当前共享 0–2 路可见视频预览，同一素材共享时间轴，其余使用封面。声音来自所选视频音轨，并保证唯一发声；进入后台或恢复时静音。图片、远程不可离线读取或缺失素材使用封面/默认外观。

## 创作剧情

1. 「工具 → 剧情编辑器」提供一条包含对白、分支、方块事件和媒体演出的模板。
2. 点节点编辑类型、文字、后继节点、条件、选项、白名单动作和本地媒体。媒体节点文字作为字幕，可设置循环和静音。导航栏「应用」提交节点修改。
3. 校验断链与循环，再进入隔离预览。预览中的模拟事件只改变预览副本，不改原世界、资源或官方进度。
4. 「保存为新剧情」创建独立身份，到剧情与任务中开始。重复发布不会覆盖旧剧情及其奖励回执。
5. JSON 导入导出只包含剧情和媒体引用，不包含视频文件。换设备后可重新绑定素材；缺失媒体不妨碍字幕和跳过。
6. 选中方块后，可在工具中的方块行为里绑定点击、接近、攻击、计时或剧情事件触发器。触发器启动受校验的剧情图，同一绑定只触发一次，已有剧情回执不重置。

## 存档与诊断

退出世界前等待保存。首次保存留下世界文件却没有活动索引时，会恢复唯一有效世界；发现多个保留世界时，可在入口直接选择恢复，建造和奖励回执保留。主文件和备份均异常时保留原文件并显示错误，不自动清空；未来版本或超限文件拒绝降级覆盖。原世界和创作副本分别保存，剧情回执、建造和掉落共同提交。

先在世界中运行一段时间，再打开「运行诊断」。工具暂停场景，暂停时间不计入帧率。诊断可分享帧间隔、p95、内存、解码器、缓存和操作耗时；它不能替代 Instruments 真机报告，详见 P10_DEVICE_VALIDATION.md。
