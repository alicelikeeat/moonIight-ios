# v1.78 真机测试清单

状态：**全部未验证**（开发环境没有 iPhone）。每项测完填“通过 / 不通过 + 说明”。建议在一台 iOS 26 设备和一台 iOS 18 设备上各做一遍。

## 玻璃外观
- [ ] 3D 世界顶栏、工具卡、工具坞、属性面板是原生玻璃，没有闪白 / 闪黑
- [ ] 摇杆底盘和摇杆头是一体的玻璃；拖动时只有摇杆头有交互高光
- [ ] 锁定准星显示正常，点它不会有反应（触摸穿透到世界）
- [ ] 2D 沙盒选中格：iOS 26 上是一圈玻璃环，格子内容清楚可见；iOS 18 上只有描边
- [ ] 深色 / 浅色模式下文字和图标清楚

## 选中与融合（3D 编辑模式）
- [ ] 点方块：出现带边线的选中框，旋转过的方块框不歪
- [ ] 底部出现“已选 N”玻璃组，带 编辑 / 复制 / 删除 / 取消选中
- [ ] 点“已选 N”：其余按钮流回胶囊里（收拢），再点又流出（展开），过程中没有跳变
- [ ] 展开过程中点任一按钮都有效，快速连点不会重复执行
- [ ] 编辑：打开属性面板；复制：在右侧出现一份并选中副本，可撤销；删除可撤销；取消选中后工具组消失
- [ ] 移动手柄拖动时来电或切后台，回来后手柄标签恢复为 X / Z / Y，方块没有被移动

## 投影与相机
- [ ] 开启“方块使用 iOS 原生玻璃”，相机静止时玻璃与方块对齐；状态行“更新 x/s”接近 0
- [ ] 快速旋转 / 移动相机：玻璃淡出，停下后约 0.2 秒淡入，没有拖影
- [ ] 横竖屏切换：玻璃先消失，稳定后在正确位置出现
- [ ] 竖屏下玻璃和方块对齐（验证视场方向）
- [ ] 角色站在方块前方时，玻璃不盖住角色；图片 / 视频面不被玻璃覆盖

## 触摸
- [ ] 点工具栏按钮之间的空白处，不会选中下面的方块，也不会移动相机
- [ ] 点状态条（生命 / 状态行）位置，触摸仍到达世界（与 v1.77 一致）
- [ ] 双指缩放、旋转、双指上下倾斜正常
- [ ] 长按不阻断单指拖动
- [ ] 摇杆连续拖动不中断，松手回中

## 无障碍
- [ ] 降低透明度：HUD 变实色，方块原生玻璃关闭，设置里的开关状态不变；关掉后恢复
- [ ] 增强对比度：玻璃组有描边，文字清楚
- [ ] 减弱动态效果：展开收拢为淡入淡出，按钮不缩放
- [ ] 动态字体最大档：选中工具组仍在屏幕内
- [ ] VoiceOver：“已选 N 个方块”“编辑”“复制”“删除”“取消选中”可读、可操作
