# v1.78 性能对照

## 现状：没有真机数据

本次开发在云端 Linux 和 GitHub macOS 构建机上进行，没有 iPhone，也不能运行 Instruments。**下表中的真机项目全部未测**，不能据此宣称性能提升。

## 已有的客观依据（源码层面，非测量）

| 变化 | 预期影响 | 依据 |
|---|---|---|
| 相机静止时方块玻璃路径不再每帧发布 | v1.77 静止时约每秒 60 次玻璃层重绘，v1.78 应接近 0 次 | `Glass3DNativeGlass.update` 只在路径变化时发布；状态行“更新 x/s”可直接读出 |
| 装饰背景去掉交互玻璃 | 少量节省 | 交互玻璃会跟踪触摸状态 |
| 选中轮廓增加边线 | 选中越多，实体越多；边线最多 60 个方块（每块 12 条） | `Glass3DRenderer.outlinedLimit` |
| 选中工具组 | 编辑模式选中时多 5 个小玻璃块，一个容器 | `Glass3DSelectionBar` |
